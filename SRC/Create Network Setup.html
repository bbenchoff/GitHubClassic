GitHub Classic

Secure networking for your Macintosh.

Prepare a one-time setup file

Open this page on your modern computer. It works offline and creates the file locally using your browser’s cryptographic random source.

  1. Create a new setup file below.
  2. Transfer the .ghsetup file to your Macintosh. Use binary transfer so its contents stay intact.
  3. In GitHub Classic, start signing in or testing the connection. In Set Up Secure Networking, choose this file.

Use a newly generated file for each Macintosh or fresh installation. Delete the modern-computer copy after transfer. GitHub Classic consumes the Mac copy once and protects subsequent network state with your local vault passphrase.
